## 📂 Featured Projects

### 🔐 [TFM-OSINT-Research](https://github.com/Vicenayarza/TFM-OSINT-Research)

Cybersecurity research project based on my **Master's Thesis**, focused on OSINT methodologies, digital footprint analysis and information gathering.

The repository documents investigation workflows, evidence handling, reporting methodology and ethical considerations.

`OSINT` `Digital Footprinting` `Cybersecurity` `Security Research`

---

### 🧠 [Offensive-Language-Detection](https://github.com/Vicenayarza/Offensive-Language-Detection)

Natural Language Processing application capable of detecting potentially offensive language in **Spanish and English** using pretrained Transformer models.

The application combines language detection, text classification and confidence analysis through an interactive interface.

`Python` `NLP` `Transformers` `PyTorch` `Streamlit`

---

### 🏀 [Castrobasket Platform](https://github.com/Vicenayarza/castrobasket-platform)

Full-stack web platform designed to manage basketball competitions, including teams, matches, standings, referees, live match management and administration.

Built as a real-world application rather than a purely academic project.

`React` `Vite` `Tailwind CSS` `Firebase` `Firestore` `Cloud Functions`

---

### 📚 [Academy Management Platform](https://github.com/Vicenayarza/academia)

Web development project focused on the management and digitalization of an **educational academy**.

The project explores the development of digital tools for organizing academic information, managing students and supporting the day-to-day operation of an educational environment.

`Web Development` `JavaScript` `React` `Firebase`

---

### 🩺 [Diabettapp](https://github.com/Vicenayarza/Diabettapp)

`Java` `Android` `Node.js` `Express` `MySQL` `Firebase`
